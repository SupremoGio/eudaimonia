06 · Navegación

Una sola jerarquía, tres superficies

Hoy la bottom nav (Inicio · Praxis · Acta · Perfil) no llega a ningún módulo, y el sidebar mete Guardarropa y Viajes dentro de Hegemonikon. V2 usa las mismas tres agrupaciones en todas partes: Hoy, Módulos y Tú.

Bottom nav · móvil

5 destinos, frecuencia diaria

Ley de Hick: lo que se usa todos los días va a una distancia de un toque.

  • Inicio · Ἀρχή — dashboard
  • Acta — registro diario
  • Praxis — tareas
  • Módulos — abre sheet con los 11 módulos + recientes
  • Tú · Αὐτός — perfil, logros, recompensas
Sidebar · desktop ≥1024

Todo el árbol, visible

Las subpáginas se muestran solo dentro del módulo activo.

  • Hoy — Inicio, Acta Diurna, Praxis, Ataraxia
  • Virtudes — Oikonomia, Hegemonikon, Paideia, Cosmopolitismo, Eurythmia
  • Vida — Guardarropa, Viajes, Harma, Plantas (salen de Hegemonikon; las rutas no cambian)
  • Tú — Logros, Recompensas, Perfil
  • Pie: saldo EC, tema, colapsar a riel de 64
⌘K · ambos

Todo lo demás, y las acciones

Busca en griego y español: «finanzas» encuentra Oikonomia.

  • Acciones — Marcar actividad, Registrar gasto, Nueva tarea, Subir estado de cuenta, Nueva prenda
  • Páginas — las ~30 pantallas, incluidas subpáginas profundas
  • Recientes — últimas 5 visitadas
  • Sistema — tema, ocultar patrimonio, cerrar sesión

11 · Plan de migración

Cinco fases, cero reescrituras

Flask + Jinja + Tailwind + JS vanilla se quedan. Cada fase se puede desplegar sola y ninguna cambia rutas ni endpoints /api.

Macro Jinja de referencia

{# templates/_ui/macros.html #}
{% macro button(label, variant='primary', size='md', icon=None, href=None, busy=False) -%}
  {% set cls = 'eu-btn eu-btn--' ~ variant ~ (' eu-btn--' ~ size if size != 'md' else '') %}
  {% if href %}<a class="{{ cls }}" href="{{ href }}">{% else %}<button class="{{ cls }}"{% if busy %} aria-busy="true"{% endif %} {{ kwargs|xmlattr }}>{% endif %}
    {% if icon %}<i data-lucide="{{ icon }}"></i>{% endif %}{{ label }}
  {% if href %}</a>{% else %}</button>{% endif %}
{%- endmacro %}

{% macro activity(a, done=False) -%}
  <button class="eu-act" data-cat="{{ a.categoria|lower }}" aria-pressed="{{ 'true' if done else 'false' }}" data-id="{{ a.id }}">
    <span class="eu-act-check"><i data-lucide="check"></i></span>
    <span class="eu-act-t">{{ a.nombre }}</span>
    <span class="eu-act-xp">+{{ a.xp }} XP{% if a.ec %} <span class="fg-ec">+{{ a.ec }} EC</span>{% endif %}</span>
  </button>
{%- endmacro %}
