# Accesibilidad — reglas que se hacen cumplir

`scripts/a11y_lint.py` revisa `gio_v3/templates/**` y `gio_v3/static/css/**` sin navegador. `pre_deploy_check.py` lo corre y **falla solo con problemas nuevos**. Los que ya estaban viven en `scripts/a11y_baseline.json` y se listan sin bloquear.

```bash
cd gio_v3
python scripts/a11y_lint.py             # todo, archivo:línea
python scripts/a11y_lint.py --nuevos    # solo lo que no está en la línea base
python scripts/a11y_lint.py --baseline  # regenera la línea base
```

La línea base no guarda números de línea. Guarda una huella por problema: regla + archivo + el código normalizado. Mover código de lugar no lo vuelve «nuevo», pero copiar un problema sí, porque cuenta como otra ocurrencia.

**Cuándo regenerar la línea base:** solo después de *corregir* problemas, para que el conteo baje. Nunca para «aceptar» uno nuevo. Si una excepción es legítima, anótala abajo, en «Excepciones», con su porqué.

Los tokens y sus contrastes viven en `static/css/app.css`. No se cambian valores de tokens; se corrige dónde se usan.

---

## `fg4-texto`: `--fg-4` no es para texto
`--fg-4` mide 2.9:1 y solo sirve para lo deshabilitado o lo decorativo. Para texto secundario se usa `--fg-3` (5.1:1).

```css
/* mal */  .hint{color:var(--fg-4)}
/* bien */ .hint{color:var(--fg-3)}
/* bien */ .eu-btn:disabled{color:var(--fg-4)}
```
```html
<!-- bien: decorativo -->
<span class="sep" aria-hidden="true" style="color:var(--fg-4)">·</span>
```
El lint lo acepta en selectores con `:disabled`, `[aria-disabled]`, `.is-disabled`, `placeholder` o `[aria-hidden]`.

## `icono-sin-nombre`: botones y enlaces de solo ícono llevan nombre
```html
<!-- mal -->  <button type="button" class="eu-iconbtn"><i data-lucide="x"></i></button>
<!-- bien --> {{ ui.iconbtn('x', 'Cerrar') }}
<!-- bien --> <a href="/perfil/" aria-label="Tu perfil"><i data-lucide="user-round"></i></a>
```

## `campo-sin-label`: todo campo tiene etiqueta
```html
<!-- mal -->  <input class="eu-input" id="q" placeholder="Buscar">
<!-- bien --> <label class="eu-label" for="q">Buscar</label><input class="eu-input" id="q">
<!-- bien --> <input class="eu-input" aria-label="Buscar" placeholder="Buscar">
<!-- bien --> {{ ui.field('q', 'Buscar') }}
```
Quedan fuera `type="hidden"` y los botones (`submit`, `button`, `reset`).

## `outline-sin-foco`: no quites el anillo de foco sin reemplazo
`:focus-visible` global ya pinta el foco. Si un componente necesita `outline:none`, tiene que tener su propio `:focus-visible` en el mismo archivo.

```css
/* mal */  .px-cap-in{outline:none}
/* bien */ .px-cap-in:focus-visible{outline:2px solid var(--border-focus)}
```
Un encabezado que solo recibe foco por código (`tabindex="-1"`) no necesita `outline:none`: `:focus-visible` no se pinta en un foco programático después de un clic.

## `onclick-sin-rol`: nada de `<div onclick>`
```html
<!-- mal -->  <div class="card" onclick="abrir()">…</div>
<!-- bien --> <button type="button" class="card" onclick="abrir()">…</button>
```
Los fondos de un diálogo que cierran con un clic fuera no van con `onclick` en la plantilla: lo maneja `euDialog`, en `static/js/eu-dialog.js`.

## `img-sin-alt`
```html
<!-- mal -->  <img src="…">
<!-- bien --> <img src="…" alt="">              <!-- decorativa -->
<!-- bien --> <img src="…" alt="Monstera en la sala">
```

## `h1-multiple`: un `<h1>` por página
El `<h1>` lo pinta `ui.page_head` con el título de `nav.py`. Las secciones usan `<h2>`, y sus partes, `<h3>`. El lint suma la página y todos sus `{% include %}`.

## Diálogos (`static/js/eu-dialog.js`)
Todo modal y toda hoja cumplen lo mismo:
- `role="dialog"`, `aria-modal="true"` y `aria-labelledby` apuntando al título;
- foco atrapado;
- Esc cierra;
- el foco regresa a quien lo abrió.

`euDialog.open(el, trigger, {onClose})` y `euDialog.close(el)` lo hacen igual para todos. Lo usan `ui.modal` (vía `euModal`), la hoja de Módulos, ⌘K, la captura rápida, el panel de avisos y el panel de plantas.

## Estados en vivo
Los toasts van por `#eu-toasts` (`aria-live="polite"`). Los contadores que cambian sin recargar también llevan `aria-live="polite"`: XP de la topbar, campana, «Hoy» de Plantas y resultados de ⌘K.

## Movimiento
`prefers-reduced-motion: reduce` apaga las animaciones globales (`app.css`). Una animación que no use `--dur-*` va dentro de `@media (prefers-reduced-motion: no-preference)`.
